# Akkira Portfolio Website

เว็บไซต์ Portfolio 3 หน้า ออกแบบตามภาพอ้างอิงในธีม Burgundy / Wine Red / Cream พร้อมแสงไล่เฉดสีชมพู

## ไฟล์
- `index.html` — Landing page
- `about.html` — About me
- `mywork.html` — My work พร้อมตัวกรองหมวดหมู่
- `style.css` — สไตล์และ Responsive layout
- `script.js` — เมนูมือถือและตัวกรองผลงาน

## วิธีเปิดใช้งาน
1. แตกไฟล์ ZIP
2. เปิดโฟลเดอร์ด้วย VS Code
3. เปิด `index.html` ด้วย Live Server (แนะนำ) หรือดับเบิลคลิกเปิดใน Browser

## ปรับแต่งก่อนใช้งานจริง
- เปลี่ยนชื่อ Akkira และข้อมูลติดต่อในไฟล์ HTML
- เปลี่ยนข้อความแนะนำตัวและรายละเอียดผลงานให้เป็นข้อมูลจริง
- ภาพบุคคล/ภาพโปรเจกต์ในตัวอย่างเป็น CSS mockup สามารถแทนที่ด้วยรูปของคุณได้
- ฟอนต์ Google Fonts ต้องใช้อินเทอร์เน็ต หากออฟไลน์จะ fallback เป็น sans-serif
